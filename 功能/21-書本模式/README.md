## 怎麼用
1. 開一篇筆記當「目錄」，用清單列出其他筆記的連結（就是功能 12 的筆記連結）：
   ```markdown
   # 115 產學合作

   - [回首頁](/)

   ## 週會議
   - [20251111_第一次會議](/abc…)
   - [20251125_第二次會議](/def…)
     - [附件](/s/xyz)
   ```
2. 在這篇筆記的「分享」→ 選「書本模式」，或直接開 `/b/<這篇的短網址>`。

## 目錄怎麼產生（`lib/book.js`）
- **標題 → 分組**（可收合）。和書名相同的標題不另外分組；底下沒有任何清單項目的標題（只是文章裡的小標）不出現在目錄。
- **清單項目 → 一頁**，取這一項的第一個連結；**巢狀清單 → 子頁**（縮排加左側細線）。沒有連結的項目當作標籤顯示。
- 連結種類：
  - 本站筆記（`/<id>`、`/s/<短網址>`、`/b/<書>/<頁>`、含網站網址的完整連結）：在書裡開 `/b/<書>/<頁>`。**讀者沒有權限的筆記顯示灰色加鎖頭**，不能點；直接打網址也會被擋（訪客轉到登入、登入但沒權限 403）。
  - 外部 `http(s)` 連結：新分頁開啟，加外部連結圖示。
  - 本站其他頁面（`/`、`/features`…）：一般連結。
  - 其他（例如 `javascript:`）：markdown-it 本來就不產生；`book.js` 也只接受上面三種。
- 書名：筆記標題；HedgeDoc 只把 `#`（一級）當標題，所以標題是「Untitled」時改用第一個任何層級的標題（hhyn 的「書本模式」筆記用的是 `##`）。
- 最多 500 個項目。

## 頁面（`public/views/book.ejs`、`lib/web/bookRouter.js`）
| 位置 | 內容 |
|---|---|
| 左側欄 | 「搜尋標題…」（即時篩選，保留符合項目的分組與上層，沒有結果時顯示提示）、重新整理、編輯目錄（開目錄筆記的編輯器）、«（收合，記在瀏覽器）；「回目錄」；目錄樹，目前這頁反白並捲到看得到的位置 |
| 頂部列 | 收合後出現的 ☰、Logo、「書名 / 目前這頁」；右邊「編輯」（開目前這頁的編輯器）、收藏（登入才有，和紀錄卡片同一份）、主題 |
| 內容上方 | 「最後由 **X** 於 2026年10月16日 編輯」（沒有編輯者紀錄時「最後編輯於 …」）；「貢獻者：」頭像（擁有者＋作者紀錄裡的人） |
| 內容 | 和發表頁一樣的閱讀排版（780px）；頁內的標題目錄改用右下角按鈕（左邊已經是書的目錄） |

- 內容裡**指向書中其他頁的連結會留在書裡**（伺服器把目錄連結→書本網址的對照表放在頁面的 JSON，`catppuccin.js` 攔截點擊）。只對照目錄裡出現的連結寫法。
- 網址統一：`/b/` 後面用短網址（或別名）；用其他寫法開會轉址到統一的網址。
- 手機（< 768px）：側欄預設收合，打開時蓋在內容上（不記住狀態）；頂部列只留目前這頁的標題。
- **沒做**：HackMD 的「追蹤」、喜歡、通知（Lilith 沒有這些功能）；瀏覽次數不因書本模式增加。
