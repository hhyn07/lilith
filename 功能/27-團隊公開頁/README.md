## 頁面
| 位置 | 內容 |
|---|---|
| `/t/<團隊>` | **任何人都看得到**（訪客也可以）。左：頭像（圖片網址，沒有就用團隊名稱第一個字）、名稱、追蹤者／貢獻者／團隊成員數、修改團隊資料（擁有者／管理者）、追蹤（登入後）、分享（複製連結）、簡介、團隊成員、貢獻者（寫過公開筆記但不是成員的人）、聯絡信箱、自訂連結。右：公開筆記數、釘選筆記（擁有者／管理者可以「選擇釘選筆記」，最多 3 篇）、所有筆記（搜尋標題、新到舊／舊到新）；每篇：更新時間、標題＋書本／筆記圖示、摘要、作者頭像、喜歡（登入後可按）、瀏覽數、收藏（登入後）、分享 |
| 團隊設定 `#profile` | 新的「團隊資料」：頭像圖片網址、簡介（300 字）、公開信箱、自訂連結（最多 5 個）；成員只能看。左側選單多一個「公開頁」連結 |
| 首頁團隊列 | 多一個「公開頁」按鈕 |
| 發表頁 `/s/…` | 收藏旁邊多一個愛心＋喜歡數；訪客只看得到數字 |

- **公開筆記**＝團隊筆記中訪客讀得到的（freely／editable／locked）。私人的團隊筆記不會出現在公開頁，也不能被釘選。
- **追蹤**：追蹤者會收到該團隊公開筆記的變更通知（通知功能 26 的一般通知；讀不到的筆記不通知）。
