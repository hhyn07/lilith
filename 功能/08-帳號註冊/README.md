## 說明
- 網頁註冊由 `config.json` 的 `allowEmailRegister` 控制，改完要**重啟伺服器**。
- **介面**：
  - 首頁右上角和簡介區，「登入」旁邊各有一顆「註冊」按鈕，會開啟獨立的註冊對話框。
  - 註冊對話框有 E-Mail、密碼、確認密碼。確認密碼由前端（bootstrap-validator 的 `data-match`）比對，兩次不一致時會顯示「兩次輸入的密碼不一致」，並停用送出鈕。
  - 登入對話框只負責登入，原本的 Register 按鈕已拿掉。
  - 只有在 `allowEmailRegister` 為 true 時才會顯示註冊按鈕和對話框，所以關閉註冊時它們會自動消失。
- **伺服器端**：`/register` 只有在註冊開啟時才存在（`lib/web/auth/email/index.js:40`）；無效的 email 會在寫入資料庫前就回 400（`:43`）。
- **替代方式**：`node bin/manage_users --add <email>`（不需要開放網頁註冊）。
