## 卡片的 ⋯ 選單（`public/js/lib/noteList.js`）
卡片右上角原本的 ✕（只會從紀錄移除）換成 ⋯。選單分組與 HackMD 相同：

| 群組 | 項目 | 誰看得到 | 做什麼 |
|---|---|---|---|
| 1 | 以瀏覽模式開啟 | 所有人 | 開 `/<id>?view` |
| 2 | 修改標題 | 擁有者 | 改寫筆記內容的第一個標題（見下方「怎麼改內容」） |
| 2 | 編輯標籤 | 擁有者 | 改寫 `###### tags:` 那一行；用逗號分隔，留空會移除 |
| 2 | 移動 | 登入者 | 選資料夾，或在同一個視窗新增資料夾並移進去 |
| 2 | 建立副本 | 登入者 | 新筆記歸自己、權限用預設值，標題加「（副本）」，出現在紀錄最上面 |
| 3 | 釘選／取消釘選 | 所有人 | 和卡片上的圖釘相同 |
| 3 | 收藏／取消收藏 | 登入者 | 卡片上出現粉色書籤 |
| 4 | 分享 | 所有人 | 複製發表頁連結 `/s/<短網址>`；私人筆記會提醒「只有你看得到」 |

| 5 | 從紀錄移除 | 所有人 | 只從你的紀錄移除，筆記還在 |
| 5 | 刪除這篇筆記（紅色） | 擁有者 | **真的刪除**，不能復原；確認視窗仿 HackMD（標題、說明、筆記名稱與時間、取消／刪除） |

- 鍵盤：⋯ 可用 Tab 移到、Enter／空白鍵打開，上下鍵移動、Esc 關閉。

## 資料夾與收藏
- 側欄「整理」區：所有筆記、收藏（數量）、資料夾清單（數量；滑鼠移上去出現重新命名／刪除）、「＋」新增資料夾。點選後篩選卡片，可以和上方的標籤篩選一起用。
- 卡片上顯示書籤與資料夾名稱。
- **每個人自己的資料夾**：資料夾和收藏是「我怎麼整理我的清單」，不會改到筆記本身，別人也看不到。
- 刪除資料夾：裡面的筆記不會被刪，回到「不放在資料夾」，收藏狀態保留。
- 資料夾最多 100 個、名稱最多 40 字。

## 怎麼改內容（`lib/noteEdit.js`）
標題和標籤本來就寫在 Markdown 裡（HedgeDoc 從內容讀出），所以「修改標題／編輯標籤」是改寫內容中的一段文字：
- **標題**：YAML front matter 有 `title:` 就改它；否則改第一個一級標題（`# 標題`，或「文字＋下一行 `===`」，可跨多行）；都沒有就在最上面加 `# 標題`。程式碼區塊裡的 `#` 會略過。
- **標籤**：front matter 有 `tags:`（含多行清單）就改它；否則改 `###### tags:` 那一行；都沒有就加在標題下面。清空時刪掉那一行；front matter 只剩 tags 時整塊刪掉（空的 `---` 區塊會被當成分隔線）。
- 標籤會去掉反引號、逗號、換行，每個最多 40 字、最多 20 個；標題最多 120 字。
- **作者標記**：用 HedgeDoc 的 `Note.updateAuthorshipByOperation` 更新，新文字算在修改的人身上，其他人的位置跟著移動。
- **筆記正在編輯器中開啟時拒絕修改**（HTTP 409，訊息「請直接在編輯器裡修改」），因為編輯器記憶體裡的版本會蓋掉資料庫的修改。
- 改完後自己紀錄中的標題、標籤也會更新（時間與置頂不變）。

## API（`lib/web/noteListRouter.js`，都要登入）
| 方法 | 路徑 | 說明 |
|---|---|---|
| GET | `/api/lilith/notes/meta` | 資料夾清單；紀錄中每篇的短網址、是否擁有、權限、資料夾、收藏 |
| POST | `/api/lilith/notes/:id/duplicate` | 建立副本（要能讀這篇） |
| POST | `/api/lilith/notes/:id/title` | `{ title }`（擁有者） |
| POST | `/api/lilith/notes/:id/tags` | `{ tags: [] }`（擁有者） |
| POST | `/api/lilith/notes/:id/meta` | `{ folderId }`／`{ starred }`（要能讀這篇；資料夾必須是自己的） |
| DELETE | `/api/lilith/notes/:id` | 刪除筆記（擁有者）；正在開啟的編輯器會收到刪除通知並回到首頁 |
| POST／POST／DELETE | `/api/lilith/folders`、`/folders/:id` | 新增、重新命名、刪除資料夾 |

- 寫入一律要求 `Content-Type: application/json`（跨站表單無法送 JSON，等於擋掉 CSRF）、每人 5 分鐘 120 次的頻率限制。
- `:id` 是紀錄用的 id（別名或編碼後的 id），短網址也可以。
