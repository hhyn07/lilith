### 實作重點
- **年份分組**：用 MutationObserver 監看 list.js 重繪 `#history-list`；依 `.timestamp` 插入年份標題。按標題排序時不分組。
- **日期列**：上游 `cover.js` 寫死了英文「visited」，而且在打包檔裡。改用 CSS 把它藏起來，排成「時鐘圖示＋日期 · 相對時間」，不需要重新打包。
- **字體**：從 Astro Scholar 專案複製 DM Sans（latin、latin-ext）和 Lilex 到 `public/fonts/lilith/`。中文用系統字體（微軟正黑體等）。沒有複製 7.8MB 的 Noto Sans SC（簡體字形）。
  - 授權：兩者都是 SIL OFL（**依我所知**；該專案資料夾內沒有附授權檔，未在本機核對）。
- **目錄**：右側目錄加上「目錄」標題，目前章節以底色高亮。
