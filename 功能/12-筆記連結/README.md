## 說明

### 操作
1. 在編輯器輸入 `[連結文字](`，游標後面會跳出筆記清單（和 HackMD 一樣：圖示、標題、`(/筆記代碼)`、副標題）。
2. 在 `(` 後面繼續打字可以篩選（比對標題或筆記代碼）。
3. 用 ↑↓ 加 Enter，或滑鼠點選：
   - **既有筆記**：插入 `/筆記代碼` 並補上 `)`；連結文字是空的（例如 `- [ ](`）時，會自動填入筆記標題。
   - **建立新筆記**（清單最後一項）：以連結文字為標題（空白時為「Untitled」）建立一篇新筆記並插入連結；新筆記的權限依 `defaultPermission`（目前是 private）。

### 清單內容
- 自己擁有的筆記（依更新時間由新到舊），副標題「我的筆記」。
- 紀錄中其他人的筆記，副標題「瀏覽紀錄」（HackMD 這裡顯示工作空間；HedgeDoc 沒有工作空間，所以改顯示來源）。
- 不列出正在編輯的這篇筆記。
- 清單在前端快取 15 秒。

### 不會觸發的情況
- 圖片語法 `![說明](`。
- 程式碼區塊內、行內程式碼內（沿用編輯器原本的判斷）。
- 未登入時。

### API（`lib/web/noteLinkRouter.js`）
| 方法 | 路徑 | 說明 |
|---|---|---|
| GET | `/api/lilith/notes?q=` | 列出可連結的筆記（最多 50 筆），回傳 `{ notes: [{ id, title, owned, time }] }` |
| POST | `/api/lilith/notes` | body `{"title": "..."}`，建立筆記，回傳 `{ id, title }`（201） |

- 兩者都要登入，未登入回 401（JSON，不轉址）。
- POST 只接受 `Content-Type: application/json`，否則回 415：跨站的表單送不出 JSON，而伺服器沒有開放 CORS，等於擋掉 CSRF。
- POST 和 `/new` 一樣有頻率限制，並遵守 `disableNoteCreation`。標題會去掉換行，最多 200 字。
- 路由要註冊在筆記路由**之前**，因為筆記路由的 `/:noteId/:action` 也會符合 `/api/...`。
