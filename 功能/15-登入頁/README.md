### 行為
- `GET /login`：已登入的人會被導回首頁。
- 首頁右上角和簡介區的「登入」按鈕都改成連到 `/login`。
- E-Mail 登入失敗 → 回到 `/login`，顯示「E-Mail 或密碼錯誤。」（原本是回首頁、顯示英文訊息）。
- ~~GitHub 登入被拒 → 回到 `/login` 顯示原因。~~ GitHub 已移除（[14](../14-第三方登入/README.md)）。
- 登入成功 → 首頁（或原本要去的頁面）。
- 註冊開啟時，下方會顯示「還沒有帳號？註冊」，連到 [16 註冊頁](../16-註冊頁/README.md)。

### 顯示密碼（`139c774`，prompt 77）
- 每個密碼欄右側有一個**眼睛按鈕**：點了顯示密碼（圖示變成斜線眼睛），再點隱藏。由 `catppuccin.js` 自動加到所有密碼欄：登入頁、註冊頁（密碼、確認密碼）、編輯使用者資料（新密碼、確認、目前密碼）、登入對話框。
- 點了之後游標和選取範圍保留在欄位裡；有 `aria-pressed`／`aria-label`（顯示密碼／隱藏密碼）給螢幕閱讀器。
- **送出表單時自動切回隱藏**，避免密碼以明文欄位送出或被瀏覽器記成一般文字。Edge 自己的顯示按鈕已隱藏，避免出現兩個眼睛。
- 瀏覽器實測：註冊頁點眼睛後欄位變成 text、按鈕和欄位上緣對齊、高度相同、欄位間距不變；送出事件後回到 password；登入頁 1 個、首頁的對話框共 4 個眼睛。
