## ① 頭像選單＋⋯ 選單（`public/views/hedgedoc/header.ejs`、`public/js/catppuccin.js`）
- **頭像選單**：只有登入者看得到。頁面先藏著，`catppuccin.js` 的 `userMenu()` 呼叫 `/me`，有登入才填入頭像、名稱並顯示。內容：
  - 頭像＋名稱＋「瀏覽公開頁面」（`/u/<使用者 ID>`）
  - 我的筆記（`/`）、編輯使用者資料（`/#edit-profile`）、登出（`/logout`）
- `/#edit-profile`：首頁讀到這個 hash 會打開「編輯使用者資料」對話框，然後把 hash 拿掉（`editProfileFromHash()`）；沒登入不開。
- **⋯ 選單**：加上圖示並分組：版本紀錄、簡報模式、發表頁面 ｜ 匯入 ▸、匯出 ▸（有設定 Dropbox／Gist／Snippet 才出現）、下載 ▸。
  - 子選單從左側展開（選單本身在畫面右邊）；滑鼠移上去或點一下都能打開；再次打開 ⋯ 時子選單會先收起來。
  - **所有 `ui-*` class 都保留**（`ui-extra-revision`、`ui-download-markdown`…），因為 `index.js` 是靠 class 綁定功能（`lib/editor/ui-elements.js`）。HMD-1 檢查這點。
  - 手機版的選單沒有改。
- 窄螢幕時「分享」會斷成兩行，加上 `white-space: nowrap`。

## ② 版本紀錄視窗（`public/views/shared/revision-modal.ejs`、`public/js/index.js`、`lib/models/revision.js`）
- 左邊「所有版本」：每個版本顯示作者頭像、相對時間（「7 小時前」，滑鼠移上去看完整時間）、作者名稱與日期；選中的版本以強調色底標示。
- 右邊上方的「與上一版本的差異」開關：開著時新增的文字是綠底＋底線、刪除的是紅底＋刪除線（改用主題顏色，原本是寫死的淺綠／淺紅，深色主題下很刺眼）；關掉時只顯示該版本的內容。
- 下方：取消、下載（.md）、還原成這個版本。
- **作者怎麼算**：HedgeDoc 的版本本身沒有記錄是誰存的，但每個版本有當時的作者標記（authorship：`[使用者 ID, 起點, 終點, 建立時間, 更新時間]`）。取「更新時間最新、而且比上一個版本新」的那筆當作者。限制：
  - 訪客的編輯不會留下作者標記，所以只有訪客改過的版本顯示「訪客 / 未記錄」。
  - 這是推算，不是精確紀錄：同一個版本裡有多人編輯時只顯示最後一位。
- 誰看得到作者：能開版本紀錄的人（能讀這份筆記的人）。編輯器本來就會把作者的名稱和頭像傳給所有讀者（作者標記），所以沒有多公開資料。

## ③ 左側目錄側欄（`public/js/index.js`、`public/js/pretty.js`、`public/js/catppuccin.js`、`catppuccin.css`）
- 檢視模式與發表頁：目錄是**貼齊閱讀區左緣**的面板（從頂部列下方到底，寬度最多 280px），目前章節會反白（沿用 Bootstrap scrollspy）。
- 面板右上角的 « 可以收合，收合後左緣留一個「目錄」小標籤，點它再打開。收合狀態存在瀏覽器（localStorage `lilith-toc-folded`），換頁、重新整理都會記得。
- 文字左側空間不夠（少於 200px）或雙欄模式時，沿用右下角的目錄按鈕，所以不會蓋到編輯區。
- 面板底部留 64px，避免被左下角的主題按鈕蓋住。

## ④ 公開個人頁 `/u/<使用者 ID>`（`lib/web/profileRouter.js`、`public/views/user.ejs`、`lib/publicNotes.js`）
- 左邊：大頭像、名稱、公開筆記數；本人看自己的頁面時多一個「修改個人資料」（連到 `/#edit-profile`）。
- 右邊：這位使用者**訪客看得到**（freely／editable／locked）、非空白的筆記卡片，最近更新的在前，最多 60 篇。卡片沿用首頁的星空紫樣式。
- 只顯示本來就公開的東西：不顯示 email、不列私人／受保護的筆記。頁面加 `noindex`（不讓搜尋引擎收錄）。
- ID 格式不對或找不到使用者：404。
- 網址用使用者 ID（UUID），因為 HedgeDoc 的使用者名稱不保證唯一。
