# 服務條款

Lilith 是 hhyn 個人架設、自用的筆記系統，不是商業服務。註冊並使用這個網站，就表示你同意以下內容。

## 帳號
- 請自行保管密碼。這裡沒有寄信重設密碼的功能，忘記密碼請聯絡站長。
- 一人一個帳號，不要把帳號借給別人使用。
- 站長可以在任何時候停用或刪除帳號，例如帳號被濫用，或網站不再開放給他人使用時。

## 你的內容
- 你寫的筆記屬於你自己。
- 請不要放違法的內容、侵害他人權利的內容，或惡意程式。
- 筆記的公開範圍由你在「分享」中設定；設成可編輯的筆記，其他人可以修改。
- 你可以隨時從使用者選單「匯出使用者資料」備份，或用「刪除使用者」刪除帳號。若也要刪除筆記，請在刪除帳號前自行刪除，或聯絡站長。

## 隱私
- 網站只保存運作所需的資料：E-Mail、加密過的密碼、顯示名稱、筆記與瀏覽紀錄。
- 這些資料不會提供給第三方，也不會用於廣告。
- 站長能接觸到伺服器與資料庫，因此在技術上看得到所有內容。請不要存放你不願意讓站長看到的資料。

## 免責
- 網站依現況提供，可能隨時中斷、變更或停止，也可能因故障遺失資料。重要的內容請自行備份。
- 站長不對使用本網站造成的任何損失負責。

## 條款變更
條款可能會更新，更新後繼續使用即表示同意新的條款。
