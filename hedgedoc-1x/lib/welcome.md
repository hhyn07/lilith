# 歡迎來到 Lilith

###### tags: `welcome` `guide`

這是你的第一篇筆記，也是一份快速上手指南。讀完之後可以直接改寫或刪掉它。

## 開始寫筆記

- 點右上角的 **建立筆記** 開一篇新的筆記。
- 第一個 `# 標題` 會成為筆記名稱，顯示在首頁的「紀錄」裡。
- 筆記會自動儲存，不需要按存檔。

## 三種檢視模式

| 模式 | 快捷鍵 | 用途 |
| --- | --- | --- |
| 編輯 | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>E</kbd> | 專心寫字 |
| 雙欄 | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>B</kbd> | 左邊寫、右邊即時預覽 |
| 檢視 | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>V</kbd> | 像讀文章一樣閱讀 |

## 用標籤整理

在筆記開頭加上一行：

```markdown
###### tags: `讀書` `技術`
```

首頁「紀錄」就能用標籤篩選，也會依年份分組。

## 常用語法

- **粗體**、*斜體*、~~刪除線~~、==螢光標記==、`行內程式碼`
- [ ] 待辦事項
- [x] 已完成的事項

> 引用一段話。

:::info
提示區塊：把 `info` 換成 `success`、`warning` 或 `danger` 可以改變顏色。
:::

```javascript=
// 程式碼區塊，語言後面加上 = 會顯示行號
console.log('Hello, Lilith')
```
